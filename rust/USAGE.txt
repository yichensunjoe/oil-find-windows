Oil Find for Windows · 预览版 v0.1（Rust 实现）

适用范围
Windows 10/11 64 位电脑上的本机文件名搜索。
不含 Pro 功能；不连接云端、不上传索引、无在线更新、无账号或激活。
不是共享盘/NAS 搜索工具，不搜索文件正文或 AI 会话。

首次使用
1. 将 ZIP 完整解压到普通用户可写的文件夹。
2. 双击 OilFind.exe，无需安装任何运行时或管理员权限。
3. 添加你允许索引的本机目录，再点击“开始索引”。默认没有选择任何扫描范围，不会自动扫描全盘。
4. 完成后在搜索框输入文件名、中文或拼音。双击结果打开；也可定位文件夹或复制路径。
5. 新文件/重命名/删除通过索引同步反映；首版采用定期目录快照而不是 NTFS USN 日志即时索引。可暂停，退出后停止。

界面操作
- 结果列表点击表头可按该列排序（文件名/完整路径/大小/修改日期），再次点击反向；表头 ▲▼ 指示当前列与方向，未排序时按搜索相关度显示。
- 右键结果行弹出菜单：打开 / 资源管理器定位 / 复制路径；Ctrl+C 等效于复制路径，Ctrl+L 聚焦搜索框，Esc 清空搜索。
- 扫描或启动加载缓存时，窗口底部细条显示不确定进度动画；标题栏与状态栏显示索引条目数（千分位）。
- 没有任何结果时，结果区显示引导文案（无索引 / 无匹配两种提示）。
- “开始索引”为默认按钮：焦点不在其他按钮上时按回车即可开始索引。

搜索示例
报告              文件名/路径包含中文
baogao / bg       中文文件名全拼 / 首字母（不含声调，多音字首读音可能不准）
report budget     同时匹配
report | budget   任一匹配
report !draft     排除 draft（可匹配路径）
"年度 报告"       带空格的词组
*.pdf             整个文件名的通配符（支持 * 和 ?；[ ] 按普通字符处理）
ext:pdf;docx       扩展名筛选
kind:image        图片；也有 doc（含 WPS/OFD）/code/folder/video/audio/archive/app
file:report       仅文件；folder:项目 仅文件夹
size:>10mb        大小；size:1mb..5mb 为范围
size:>=1kb        支持 >、>=、<、<=、=
dm:today          今天；dm:week 为最近7个日历日
dm:2026-10-01     指定日期；dm:2026-10-01..2026-10-24 为闭日期范围
path:设计         路径包含
regex:^IMG_\d+    不区分大小写的正则；用带空格的 | 组合正则与其他 OR 条件

安全与索引
- 只读取文件名、路径、大小、修改时间，不读取文件内容。
- 不删除、不移动、不重命名文件，不更改文件权限。
- 跳过：依赖与版本库目录（node_modules/.git 等）、私人运行器目录（.claude/.codex/.workbuddy 等）在任意层级；
  C:\Windows、C:\Program Files、C:\ProgramData、$RECYCLE.BIN 等系统目录仅在磁盘根目录一级跳过，
  因此 D:\code\myproject\windows 或 D:\work\tmp 这类普通项目目录仍可搜索。
- 跳过符号链接与目录联接；不支持 UNC/网络映射盘。OneDrive 占位文件如果带 reparse 属性会被跳过。
- 无法读取的路径会跳过并计数；管理员权限不是使用前提。
- 缓存和配置在 %LOCALAPPDATA%\OilFind（不使用漫游配置目录，避免把大索引同步到服务器）。
- 搜索结果最多显示 2000 条，但同时展示总命中；索引上限 200 万条，超限会报错，不覆盖已有完整索引。
- 不保证达到上游 Mac SIMD/Everything 的性能，建议先索引工作目录，不要一开始选择整盘。
- 文件由你明确操作后交给 Windows 关联程序打开；请勿打开不可信文件。

安装与签名
预览版可执行文件未代码签名，Windows SmartScreen 或安全软件可能提示未知发布者。
下载渠道与是否签名由分发者决定；不要为此关闭系统防护或绕过安全策略。

离线包包含
OilFind.exe              原生桌面客户端
oilfind-cli.exe         诊断 CLI（默认只查缓存；扫描必须显式 -scan -root）
LICENSE                 上游 MIT 许可
THIRD_PARTY_NOTICES.txt  第三方 crate 许可证清单
USAGE.txt               本说明

CLI 示例（仅对显式授权的目录操作）
oilfind-cli.exe -scan -root "D:\Work" -query "ext:pdf" -limit 100
oilfind-cli.exe -query "baogao"

源码位置
Windows 实现在 rust/（cargo workspace：oilfind-core / oilfind-win / oilfind-cli）；macOS 源码保留在 Sources/。
Windows 版重新实现了本地遍历/搜索与 Win32 界面，沿用上游公开功能和语法设计，不是把 Swift/AppKit 直接编译成 Windows。
开发者构建需要 Rust 1.92（rust/rust-toolchain.toml 已固定），运行端不需要。
